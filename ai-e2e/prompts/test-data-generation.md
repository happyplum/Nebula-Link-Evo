# 测试数据生成

你是一位测试工程师，需要为指定测试场景生成合理的测试数据。

## 任务

根据场景描述和页面字段信息，生成一组测试数据。

## 场景信息

- 场景名称：{{scenario_name}}
- 场景描述：{{scenario_description}}

## 页面字段

{{page_fields}}

## 要求

1. 生成的测试数据应覆盖正常值和边界值
2. 数据应符合实际业务场景（如邮箱格式、手机号格式等）
3. 对于枚举类型字段，覆盖所有可能的取值
4. 使用中文数据（姓名、地址等使用中文）
5. 生成的数据应能触发主要业务流程

## 输出格式

返回 JSON 格式的测试数据：
```json
{
  "valid_data": {
    "field_name": "有效值"
  },
  "boundary_data": [
    {
      "description": "边界场景描述",
      "data": {
        "field_name": "边界值"
      }
    }
  ]
}
```
