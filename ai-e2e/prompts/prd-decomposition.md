# PRD 功能模块分解任务

你是一位资深的业务分析师和系统架构师，擅长将业务模块分解为可测试的功能模块。

## 任务

将以下 L1 业务模块分解为 L2 功能模块。

## 业务模块

- 名称：{{business_module_name}}
- 描述：{{business_module_description}}

## PRD 上下文

{{prd_context}}

## 要求

1. 将业务模块分解为可独立测试的功能模块（L2）
2. 每个功能模块应有明确的用户操作路径
3. 功能模块粒度适中：既不过于宽泛也不过于细碎
4. 考虑正常流程和异常流程
5. 每个功能模块描述应包含：
   - 模块名称
   - 功能描述
   - 涉及的页面/路由
   - 核心交互元素

## 输出格式

返回 JSON 数组，每个元素包含：
```json
[
  {
    "name": "功能模块名称",
    "description": "功能描述",
    "pages": ["涉及的页面路由"],
    "key_elements": ["核心交互元素列表"]
  }
]
```
